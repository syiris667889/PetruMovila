# Digital Heritage Atlas — Petru Movilă

Static educational website built with HTML, CSS, JavaScript and Leaflet. Designed for GitHub Pages.

## Run locally
Open `index.html` in a browser. For the best experience, use VS Code with the Live Server extension.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `petru-movila-atlas`.
2. Upload `index.html`, `style.css`, `script.js`, and this README (plus any images you add).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Notes
- The map uses Leaflet and OpenStreetMap tiles, so an internet connection is required for the map.
- Fonts, Leaflet, and map tiles load from external services.
- Historical place markers represent contextual locations; they do not claim an exact proven travel route.
- Verify historical dates and image licensing before presenting the project.
